Pastel 20260928 更新内容：

1. 左侧新增 Mac 端：在 iPhone、iPad、Vision 之外增加 Mac 搜索入口（参考 majd/ipatool 的 macSoftware 平台与 IPA-Tool-3.0 的 Mac 搜索），Mac App 显示 Mac 平台标记，已下载的 Mac App 可一键反查。

3. 接入 Sparkle 自动更新：应用会从 GitHub 的 appcast 检查新版本，支持菜单「检查更新…」与设置页「检查更新」；更新包使用 EdDSA 签名，安装前校验签名，配置改为指向本仓库地址。
